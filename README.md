Запуск без сервера: START.cmd открывает index.html в браузере. Python не требуется. CSV, XLSX и фото обрабатываются в браузере. Ссылка 127.0.0.1 больше не нужна.

# Каталог за вечер — локальный прототип

Запуск: дважды нажмите START.cmd (нужен Python 3). Адрес: http://127.0.0.1:8765.
Сервер слушает только 127.0.0.1. Публикации, внешних запросов, оплаты и API моделей нет.

Работает: фото PNG/JPG/WebP, импорт CSV и первого листа XLSX без пароля, редактирование, проверка пропусков и дубликатов артикулов, 3 шаблона, цвет, блоки характеристик, предпросмотр, локальная сборка, PNG и ZIP, история, обращения и панель владельца.

Порядок: открыть пример → исправить размеры третьего товара → выбрать стиль → подтвердить данные → собрать → скачать ZIP.

Свои данные: скачайте шаблон CSV. Обязательные столбцы Артикул и Название. Фото с именем HOME-001.jpg привязывается к артикулу HOME-001. Для сборки нужны фото, название, артикул, материал и размеры каждого товара. До 30 товаров, фото до 10 МБ. Изображения уменьшаются для локального хранения; оригиналы храните отдельно.

Данные в localStorage текущего браузера. Очистка браузера удалит данные. Большой каталог может превысить квоту localStorage: скачивайте результат и используйте небольшие партии. XLSX распаковывается локальным сервером в памяти, не сохраняется на диск. Имена загруженных товаров и характеристики не отправляются наружу.

Нейросеть НЕ подключена. Фон не удаляется и не генерируется, реальная фотография помещается в шаблон. Нельзя оценивать по прототипу качество будущей нейрообработки. Нет аккаунтов, безопасности для публичной эксплуатации, фоновой очереди, платежей, реальных уведомлений и серверного хранения. Перезапуск страницы прерывает незавершённую сборку. Готовые сборки сохраняют собственный снимок каталога и оформления.

Для остановки: Ctrl+C в окне сервера. Не открывайте этот прототип в интернет.
